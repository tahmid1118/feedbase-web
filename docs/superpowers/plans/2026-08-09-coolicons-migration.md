# Coolicons Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace every icon in the FeedBoard frontend (85 distinct `lucide-react`
icons across 84 files, including shadcn/ui primitives) with icons sourced from
coolicons (free tier, CC BY 4.0), hand-drawing the ~9 names with no free
coolicons equivalent in the same visual style, then remove the `lucide-react`
dependency entirely.

**Architecture:** A new `components/icons/` directory holds one React component
per unique icon glyph (78 files), each a thin `<svg>` wrapper matching lucide's
prop contract (`size`, `className`, `strokeWidth`, arbitrary SVG props).
`components/icons/index.ts` re-exports all **85** lucide names — including 7
pairs that collapse onto a single shared glyph (e.g. `Check` and `CheckIcon` are
literally the same icon, exported under both names) — so that swapping a call
site is a pure import-path change, never a rename. 67 of the 78 files are
generated by a one-time codegen script that fetches the exact SVG path data
from the real coolicons GitHub repo; 3 are hand-composed from existing
coolicons paths (a mirror, a stack, a composite); 8 are fully hand-drawn using
the same `24×24`, `currentColor`, 2px round-cap stroke contract, using safe
primitives (`<circle>`, `<rect>`, `<line>`, `<path>` with only `M/L/H/V/C/Z`
commands — no hand-computed arc radii, which are the one thing that can render
subtly wrong without a browser to check).

**Tech Stack:** Next.js 16 / React 19 / TypeScript, existing shadcn/ui + Tailwind
setup. No new runtime dependencies — icons are inlined React components, not a
runtime SVG-fetching library.

## Global Constraints

- Every icon component's prop type is `IconProps` (`components/icons/types.ts`):
  `interface IconProps extends React.SVGProps<SVGSVGElement> { size?: number | string }`.
  `strokeWidth` is already part of `React.SVGProps<SVGSVGElement>`, so it needs
  no separate declaration.
- Every icon's root `<svg>` sets: `xmlns="http://www.w3.org/2000/svg"`,
  `viewBox="0 0 24 24"`, `fill="none"`, `stroke="currentColor"`,
  `strokeWidth={strokeWidth}` (destructured with a default of `2`),
  `strokeLinecap="round"`, `strokeLinejoin="round"`, `width={size}`,
  `height={size}` (both destructured with a default of `24`), then
  `{...props}` spread **last** so a caller can override anything.
- Coolicons source SVGs come from
  `https://raw.githubusercontent.com/krystonschwarze/coolicons/master/coolicons%20SVG/<Category>/<File>.svg`
  — confirmed live and CC BY 4.0 licensed during planning (every URL used below
  was fetched and returned `200` with exactly the path data quoted).
- `components/icons/index.ts` is the **only** import path any call site uses —
  `import { Trash2 } from "@/components/icons"` — never a deep import into an
  individual icon file from outside `components/icons/`.
- Nothing in this plan touches `components/ui/logo.tsx`, `public/icon.svg`,
  `public/logo.svg`, `logo-120.png`, `logo-512.png`, `public/favicon.ico`, or
  the backend's `assets/app-icon.svg` — those are the FeedBoard brand mark, out
  of scope per the design spec.

function extractPaths(svg) {
  const paths = [...svg.matchAll(/<path[^>]*\bd="([^"]+)"/g)].map((m) => m[1]);
  if (paths.length === 0) {
    throw new Error("no <path d=\"...\"> elements found in SVG source");
  }
  return paths;
}

function componentSource(name, paths) {
  const pathTags = paths.map((d) => `      <path d="${d}" />`).join("\n");
  return `import type { IconProps } from "./types";

export function ${name}({ size = 24, strokeWidth = 2, ...props }: IconProps) {
  return (
    <svg
      xmlns="http://www.w3.org/2000/svg"
      width={size}
      height={size}
      viewBox="0 0 24 24"
      fill="none"
      stroke="currentColor"
      strokeWidth={strokeWidth}
      strokeLinecap="round"
      strokeLinejoin="round"
      {...props}
    >
${pathTags}
    </svg>
  );
}
`;
}

async function main() {
  await mkdir(OUT_DIR, { recursive: true });
  for (const [name, category, file] of ICONS) {
    const url = `${BASE}/${category}/${encodeURIComponent(file)}.svg`;
    const res = await fetch(url);
    if (!res.ok) {
      throw new Error(`fetch failed (${res.status}) for ${name}: ${url}`);
    }
    const svg = await res.text();
    const paths = extractPaths(svg);
    const source = componentSource(name, paths);
    const outPath = path.join(OUT_DIR, `${name}.tsx`);
    await writeFile(outPath, source, "utf8");
    console.log(`wrote ${name}.tsx (${paths.length} path${paths.length > 1 ? "s" : ""})`);
  }
  console.log(`done: ${ICONS.length} icons generated`);
}

main().catch((err) => {
  console.error(err);
  process.exitCode = 1;
});

```js
// One-time codemod: every icon name lucide-react exported that this project
// used is now re-exported under the identical name from
// "@/components/icons" (see components/icons/index.ts), so migrating a call
// site is purely a matter of changing the import's source string — no
// identifier in any JSX tag or import list needs to change.
import { readFile, writeFile } from "node:fs/promises";
import path from "node:path";
import { fileURLToPath } from "node:url";

const __dirname = path.dirname(fileURLToPath(import.meta.url));
const ROOT = path.join(__dirname, "..");
// Files under components/icons/ never import "lucide-react" (they only
// import from "./types"), so walking into that directory is harmless — the
// `!src.includes("lucide-react")` check below skips them on its own. Only
// node_modules/.next/.git are worth skipping for speed.
const SKIP_DIRS = new Set(["node_modules", ".next", ".git"]);

async function walk(dir, out) {
  const { readdir } = await import("node:fs/promises");
  for (const entry of await readdir(dir, { withFileTypes: true })) {
    if (SKIP_DIRS.has(entry.name)) continue;
    const full = path.join(dir, entry.name);
    if (entry.isDirectory()) {
      await walk(full, out);
    } else if (/\.(tsx|ts)$/.test(entry.name)) {
      out.push(full);
    }
  }
}

async function main() {
  const files = [];
  await walk(ROOT, files);

  const changed = [];
  for (const file of files) {
    const src = await readFile(file, "utf8");
    if (!src.includes("lucide-react")) continue;
    const next = src
      .replace(/"lucide-react"/g, '"@/components/icons"')
      .replace(/'lucide-react'/g, "'@/components/icons'");
    if (next !== src) {
      await writeFile(file, next, "utf8");
      changed.push(path.relative(ROOT, file));
    }
  }

  console.log(`updated ${changed.length} files:`);
  for (const f of changed) console.log(`  ${f}`);
}

main().catch((err) => {
  console.error(err);
  process.exitCode = 1;
});
```
